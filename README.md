# raghuramreddy.tech

Personal portfolio website.

Live: [https://raghuramreddy.tech](https://raghuramreddy.tech)

## Local Run

```bash
python -m http.server 8080
```

Open: `http://localhost:8080`

## Project Structure

- `index.html` - Home page
- `pages/` - Site pages and articles
- `assets/css/` - Styles
- `assets/js/` - Scripts
- `assets/data/` - Content data
